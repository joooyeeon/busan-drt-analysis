# 변경 이력 및 실행 확인

## 2026-10-09 업데이트

이번 버전은 기존 버스의 추정 운임수입을 일별 재정 비교에 반영합니다.

- `drt_daily_analysis.py`: 기존 버스 수입을 차감한 절감액, 수입을 포함한 손익분기 회피원가 비율, 절감액 중앙값 및 비용 검수표를 사용합니다.
- F2는 실현가능한 날짜의 회피가능 버스 순비용과 DRT 순비용을 비교합니다. 실현가능일 수와 경제적 평일 수를 CSV에 함께 기록합니다.
- README, 분석 방법, 결과 열 설명을 해당 계산식에 맞춰 갱신했습니다.

두 핵심 Python 파일은 이번 첨부 압축파일의 바이트를 그대로 사용합니다. 이전 첨부 원본과 비교하면 `drt_daily_analysis.py`만 변경되었고, `drt_model_student.py`와 원본 전처리 노트북 2개는 동일합니다. 수리모형, 비용 입력값, 서비스 기준, 대상 기간·노선은 동일합니다.

## 전처리 구성

전처리는 `scripts/`의 Python 파일과 이를 호출하는 `notebooks/`로 제공합니다. 개인 컴퓨터의 절대 경로와 과거 노트북 실행 결과를 포함하지 않습니다. 일별 집계는 파일명과 날짜를 모두 2025년 11월로 제한합니다. `data/templates/`에는 실제 값을 채우기 위한 빈 입력 양식이 있습니다.

원자료, 실제 `boardings_daily.csv`·`routes_daily.csv`, 연구 결과는 제공하지 않습니다. 실제 연구 수치를 재현하려면 해당 입력값이 필요합니다.

## 실행 확인 범위

- 환경: Python 3.12.14, NumPy 2.3.5, pandas 2.2.3, SciPy 1.17.0, Matplotlib 3.10.8.
- Python 문법과 노트북 구조를 확인했습니다.
- 테스트 입력 5개 노선 × 평일 20일로 CSV 3개와 F1·F2·F4 그림 3개가 생성되는지 확인했습니다.
- 동일한 테스트 입력의 이전 결과와 비교해, 서비스 통과 차량수와 DRT 순비용이 유지되고 절감액·손익분기 비율에 기존 버스 수입이 반영되는지 확인했습니다.
- F2 검수표의 실현가능일 수·경제적 평일 수·비용 중앙값·일별 절감액 중앙값을 날짜별 결과와 대조했습니다.

이 검증은 코드 실행 및 계산식 확인입니다. 실제 연구 결과 수치의 재현 검증은 수행하지 않았으며 테스트 입력·출력은 배포 파일에 포함하지 않습니다. 한국어 그림은 코드가 검색하는 Malgun Gothic, AppleGothic, NanumGothic, Noto Sans CJK KR/JP 중 사용 가능한 글꼴을 사용합니다.
