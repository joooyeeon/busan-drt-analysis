# GitHub 정리 내역

## 유지한 부분

- 첨부 `drt_daily_analysis.py`, `drt_model_student.py`는 원본 바이트 그대로 유지했습니다.
- 수리모형, 비용 입력값, 최적안 선택 방식, 그림의 문구·크기·색상·배치를 유지했습니다.
- 분석에 필요한 실제 수요와 노선별 모수는 새로 추정하거나 만들어 넣지 않았습니다.

## 정리한 부분

- 한국어 README, 의존성 목록, 데이터 설명, 방법론 문서를 추가했습니다.
- 원자료·개인 입력값·생성 결과가 기본적으로 Git에 포함되지 않도록 `.gitignore`를 추가했습니다.
- 노트북의 실행 기록을 제거했습니다. 첨부 노트북에는 현재 5개 노선 코드와 맞지 않는 과거 실행 결과가 남아 있어, 해당 출력을 연구 결과로 옮기지 않았습니다.
- Windows의 개인 경로를 제거하고 프로젝트 상대 경로와 `--raw-dir` 실행 인자를 사용하도록 정리했습니다.
- 노트북의 전처리 내용을 `scripts/`의 Python 실행 파일로 옮겼고, 노트북은 같은 함수를 호출하도록 구성했습니다.
- 운영시간 추정 결과를 콘솔 출력과 함께 CSV 2개로 저장하도록 추가했습니다.
- 잘못된 폴더·빈 자료에 대한 오류 메시지와 독립적인 입력 검증 코드를 추가했습니다.

## 전처리에서 명시적으로 바뀐 부분

원본 승차인원 노트북은 모든 `TRN001_*.csv`를 읽고 2025년만 필터링했습니다. 정리본은 파일명과 날짜를 모두 **2025년 11월**로 제한합니다. 원래 폴더에 11월 자료만 있었다면 분석 대상은 같습니다. CSV 열은 문자열로 읽어 승차 상태와 노선번호가 숫자로 자동 변환되지 않도록 했습니다.

승차인원 합산, 대상 5개 노선, 주말 제외, 업체명으로 지하철 기록 제외하는 방식은 유지했습니다. 운영시간 추정의 HHMM 해석, 자정 이후 날짜 조정, 300분 이상 조건, 중앙값 집계도 유지했습니다.

## 실행 시 알아둘 점

- 원본 분석 코드는 `data/`의 두 CSV를 읽고 `outputs_daily/`에 결과를 저장합니다.
- 실행하면 같은 이름의 CSV·그림을 다시 저장하며, 원본에 포함된 F0·F3·F5 그림 정리 동작도 유지합니다.
- 한국어 그림을 보려면 원본 코드가 검색하는 글꼴 중 하나가 필요합니다: Malgun Gothic, AppleGothic, NanumGothic, Noto Sans CJK KR/JP.
- 비용 금액은 첨부 코드의 설정값입니다. 외부 공적 자료의 출처를 이번 정리 과정에서 새로 확인한 것은 아닙니다.

## 검증

- 환경: Python 3.12.14, NumPy 2.3.5, pandas 2.2.3, SciPy 1.17.0, Matplotlib 3.10.8.
- Python 문법과 노트북 JSON·코드 셀을 확인했습니다.
- 핵심 분석 파일 두 개가 첨부 원본과 바이트 단위로 동일함을 확인했습니다.
- 테스트용 TRN001 30개 파일에서 5개 노선 × 평일 20일 = 100행 집계를 확인했습니다.
- 승차·하차·대상 노선·업체명 필터와 `탑승인원` 합산, 운영시간 중앙값을 확인했습니다.
- 같은 11월 테스트 자료에서 두 전처리 결과가 원본 노트북의 계산 결과와 일치했습니다.
- 10월 파일과 11월 파일 안의 12월 기록이 일별 집계에서 제외되는지 확인했습니다.
- 입력 검증기가 빈 양식, 중복 행, 음수 승차인원, 누락 날짜를 거부하는지 확인했습니다.
- 테스트 입력으로 원본 일별 분석을 실행해 CSV 3개와 F1·F2·F4 그림 3개 생성을 확인했습니다.

실제 원자료와 노선별 입력값이 없으므로 실제 연구 결과 수치의 재현 검증은 수행하지 않았습니다. 테스트 입력·결과는 배포 압축파일에 포함하지 않았습니다.
