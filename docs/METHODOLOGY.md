# 분석 방법과 지표 해석

이 문서는 함께 제공된 `drt_daily_analysis.py`와 `drt_model_student.py`의 실제 계산을 설명합니다. 원본의 수리모형·비용식·그림 코드는 변경하지 않았습니다.

## 1. 일별 수요를 도착률로 변환

날짜별 승차인원을 $B_d$, 노선별 하루 운영시간을 $T$분이라 하면 도착률은 다음과 같습니다.

$$\lambda_d = B_d / T$$

단위는 **명/분**입니다. 하루 전체를 대표하는 일정 도착률을 사용하는 분석이며, 시간대별 수요 프로파일을 추정한 결과가 아닙니다.

## 2. 서비스 기준을 만족하는 차량수 탐색

차량수 $M$마다 평균 대기시간과 이용유지율의 평형을 계산합니다. 아래에서 이용유지율은 $r$로 표시해 회피원가 비율과 구분합니다. 모델 파일에서는 이용유지율에 `alpha`라는 변수명을 사용합니다.

$$\tau_c = \tau_p + \tau_b + \tau_e$$

$$W(r,M) = \tau_p + \frac{1}{\kappa(bM-r\lambda_d\tau_c)}$$

분모의 여유 용량이 0 이하이면 대기시간은 무한대로 처리합니다. 이용유지율은 다음 고정점 방정식으로 결정됩니다.

$$r = \frac{1}{1+\exp[-(a_0-\beta W(r,M))]}$$

| 공통 모수 | 값 | 의미 |
| --- | --- | --- |
| `b` | 2.0 | 1회 배정당 평균 합승 인원 |
| `kappa` | 0.15 | 배정계수 |
| `a0` | 2.0 | 기본 선호도 |
| `beta` | 0.12 | 대기시간에 따른 효용 감소 계수 |
| `theta` | 5.0 | 학생용 모형의 적응 시간척도; 일별 평형 계산에는 직접 사용되지 않음 |

서비스 통과 조건은 $W\leq10$분, $r\geq0.75$입니다. 이 조건을 만족하는 가장 작은 $M$을 `min_M_service`에 기록합니다.

탐색 상한은 각 노선 최대 일수요를 이용해 `max(40, ceil(최대 도착률 × 사이클시간 / b) + 30)`으로 설정합니다. 유한한 탐색 범위 안에서의 최소·최적 값입니다.

## 3. 비용 비교와 차량수 제약

현재 버스 대수를 $N$이라 하면, 현행 버스 하루 총비용은 다음과 같습니다.

$$C_B = N \times 834{,}327$$

DRT 하루 순비용은 다음과 같습니다.

$$C_D(M) = M \times 551{,}372 - 1{,}500 \times B_d \times r(M)$$

분석은 서비스 기준 통과안 중 **$M\leq N$인 안**을 실현가능한 후보로 취급합니다. 그중 DRT 순비용이 최소인 안이 `best_feasible_M`입니다. 현재 버스 대수와 비교하는 제약은 이 연구의 선별 기준이며, 차량 크기·운전인력·실제 배차가 같은 조건이라는 증거는 아닙니다.

회피가능 원가 비율을 $s$라고 할 때 시나리오별 절감액은 다음과 같습니다.

$$S_d(s)=sC_B-\min_{M\in\text{실현가능 후보}}C_D(M)$$

`70%`를 본문 기준안으로 사용하고 `50%`를 민감도, `100%`를 상한 시나리오로 함께 계산합니다. 경제성이 있는 날짜는 절감액이 **엄격히 0보다 큰 날**입니다. 실현가능 후보가 없으면 절감액과 경제적 차량수는 빈값으로 둡니다.

### 손익분기 회피원가 비율 α*

$$\alpha_d^* = \frac{\min_{M\in\text{서비스 통과 후보}}C_D(M)}{C_B}$$

원본 코드는 이 지표를 계산할 때 현재 버스 대수 상한을 적용하지 않습니다. 따라서 `alpha_star_M`과 `best_feasible_M`은 다를 수 있고, **α*가 70%보다 작더라도 실제로 차량수 조건을 만족한다고 단정할 수 없습니다.** 제약을 만족하는 후보에 대한 절감 여부는 `daily_saving_70`과 `economic_M_70`에서 확인합니다.

F1의 노선별 α*는 일별 α*의 중앙값입니다. 차량수 조건에 실패한 날의 α*를 임의의 1.05로 바꾸지 않으며 계산 가능한 값은 그대로 남깁니다. 1보다 큰 값도 표시합니다.

### 기존 버스 운임수입의 처리

현재 일별 분석의 최종 절감액 계산에는 **현행 버스 운임수입을 별도로 차감하지 않습니다.** DRT 쪽에는 모형상 유지된 승객의 운임수입이 반영됩니다. 따라서 이를 양쪽 운임수입을 모두 차감한 회사 회계상 순손익과 동일하게 해석하지 않습니다.

학생용 `candidate_table()` 내부의 `daily_saving`은 현행 운임수입도 차감하는 별도 정의입니다. 일별 분석 파일은 이 내부 절감액을 최종 시나리오 결과로 사용하지 않고, 위의 $S_d(s)$ 식으로 다시 계산합니다.

## 4. 노선별 집계와 그림

- `mean_boardings`: 분석된 날짜들의 평균 승차인원
- `median_required_M`, `p95_required_M`, `max_required_M`: 일별 최소 서비스 통과 차량수의 중앙값·95백분위·최댓값
- `economic_day_rate_70`: 전체 분석 날짜 중 서비스·차량수 조건과 양의 70% 절감액을 만족한 비율
- `mean_daily_saving_70`: 실현가능안이 있는 날짜들의 평균 70% 절감액

F2는 현재 버스 총비용에 50%·70%·100%를 곱한 금액과 실현가능 DRT 순비용의 중앙값을 비교합니다. 그림의 차량수 충족 여부는 일별 필요 차량수의 **중앙값**으로 요약하므로, 모든 날짜에 조건을 만족하는지는 `feasible_day_rate`와 날짜별 결과로 확인합니다.

F1의 가로 노선 순서는 520 → 180 → 36 → 10 → 68이며, F2는 520이 맨 아래입니다. F4는 원본 배치를 유지해 윗줄에 180·36·10, 아랫줄에 520·68을 표시합니다.

## 5. 재현 범위

일별 평균을 이용한 1차 선별 모형입니다. 이 분석 실행은 실제 수요의 학습·검증 분할, 시간대별 첨두 대기열, 개별 차량 경로 최적화, 대기시간 P95 검증을 수행하지 않습니다. `p95_required_M`은 날짜별 필요 차량수의 백분위이며, 대기시간 P95가 아닙니다.

원본 `drt_model_student.py`를 직접 실행하면 학습용 가상자료 분석이 별도로 실행됩니다. 해당 파일의 기본 비용과 운영시간은 일별 분석의 입력값과 다르므로, 연구 분석의 실행 진입점은 `drt_daily_analysis.py`입니다.

원자료와 실제 `routes_daily.csv`가 제공되어야 연구 결과를 재현할 수 있습니다. 이번 정리에서는 임의의 모수로 연구 결과를 채우지 않았습니다.
